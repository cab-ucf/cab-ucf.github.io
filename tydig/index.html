tydig

Typst, decentralized collaboration with iroh, saved in git. Source

Run

  • Needs podman (with podman compose) and just.
  • just builds and starts the hub on :8080, then prints its link.
  • Data lives in ./data (TYDIG_DATA). Back it up, or give each project a git remote.
  • To isolate it, run just as an account of its own. On NixOS, import nixos.nix: it makes the account and updates hourly.
  • just down, just logs, just passwd EMAIL (no mail: prints a new password).

Share

  • The link (https://cxn.pub/#…) opens the editor in any browser; after just publish, plain cxn.pub does too (sign-in and invitations still decide who gets in). It reaches the hub over iroh, end to end encrypted, through NAT: no domain, certificate or open port.
  • Invite-only: the first account is free. Settings › Share adds an address and shows its invite link.
  • The link names a key only the hub holds (data/link-seed; delete it for a new link).
  • Firefox: n0's relays refuse its ECH GREASE. Set security.tls.ech.grease_probability to 0, or use another browser.
  • Your own static site: fork, set the repo variables TYDIG_HUB (the id after #) and TYDIG_BRAND, and give it a domain of its own. Whoever serves the page can read what visitors type.

Write

  • A pre-registered report: prose written before the results, numbers computed by the build (make). 
    #let R = json("build/results.json")
The water was #if R.T1 > R.T2 [cooling] else [heating].
  • Live preview in the browser, multi-cursor editing, comments pinned to the preview, a Discussion.
  • Select text for a 💬 comment button. discuss in the bar counts what is new; @name tells a person or asks an agent.
  • Keys: Ctrl/⌘-K any command, -P open a file, -S save, -Alt-M comment, -B/-I bold/italic, Esc leaves focus.
  • Builds run in a sandbox: 2 CPUs, 2 GB, 180 s, no capabilities, public HTTPS only.
  • Ctrl-S commits, signs (ML-DSA-65, the key never leaves the device) and pushes. History restores any commit.
  • Cite: PubMed and Crossref; BibTeX from the registrar; "Check references" catches made-up ones.
  • Spelling and grammar by Harper, in the browser. A word is marked only when it looks like a slip, so your field's terms are left be; ~98,000 medical terms (wordlist-medicalterms-en, GPL-3.0) are known. Word export with live EndNote fields.
  • Upload a .zip/.tar.gz to update a project; File › Download for the sources.
  • Paths in Typst start from the file naming them; /fig.svg starts at the project root.

Templates

  • report, and grants: NIH R03, R21, R25 SEPA, R35 MIRA; NSF CMI GOALI. Grey prompts quote the funder: check the current solicitation.
  • Grants: make all (each attachment), make full (one PDF and what is missing), make budget (Excel). The checklist shows package.yaml, live.
  • A template is a folder in templates/; nih-r21 layers on nih, which base.json puts on grant. brand-<x> goes last.
  • Switching template merges three ways: your writing stays; a rewritten file lands beside yours (main.nih-r21.typ).

Agents and models

  • Settings › Share › Agents gives a token. Any MCP client plugs in: 
    claude mcp add --transport http tydig <hub>/api/agent/<project>/mcp \
  --header "Authorization: Bearer tyd_..."
  • TYDIG_AGENT_TOKEN=tyd_... just agent PROJECT answers each @name mention with Claude Code.
  • Ghost text: TYDIG_OLLAMA + TYDIG_GHOST_MODEL (e.g. qwen2.5-coder:1.5b), or each person's own Ollama with OLLAMA_ORIGINS set to the page.
  • Surprise overlay: TYDIG_SCOPE=1 runs Perplexiscope (scope/): word surprise, flatness, and AI-likeness by MELD. A flag is evidence to discuss, never a verdict.

Settings (.env)

TYDIG_URLthe address people open (sign-in checks it); behind TLS also TYDIG_TRUST_PROXY=1
TYDIG_SSO_DISCOVERY, _CLIENT_ID, _CLIENT_SECRET, _LABEL, _ONLYinstitutional sign-in (OIDC); redirect URI <url>/api/auth/oauth2/callback/sso
TYDIG_SIGNUP=openanyone who reaches the hub may sign up
TYDIG_LINK=0, TYDIG_LINK_RELAY, TYDIG_PAGEno link; pin one relay; another static site
TYDIG_MAX_BUILDS, TYDIG_BUILD_NET=0, TYDIG_QUOTA_MBbuilds at once (2); no network for builds; MB per project (1000)
TYDIG_GIT_PRIVATE=1, TYDIG_GIT_PUSH_MINUTESallow remotes on the hub's network; push interval (5)
TYDIG_SCOPE_MODEL, TYDIG_SCOPE_DETECTOR=, TYDIG_GPU=nvidia.com/gpu=all + TYDIG_TORCH=cu130another attention-only base model; no MELD; a GPU
TYDIG_BRAND, TYDIG_TEMPLATESthe editor's look (client/brands/); another templates folder

Troubleshooting

  • "Invalid origin": open the hub at TYDIG_URL, or set it to the address you use.
  • Builds fail to start: systemctl --user status podman.socket, then just.
  • The link never connects: the hub needs outbound HTTPS to its US East relays (iroh.cxn.center, use1-1.relay.n0.iroh.link).
  • A private git remote: give its git@ URL, add the key the hub shows as a deploy key with write access.
  • Typst "access denied": a file the document reads is missing; build output appears after make.

Design

  • One hub per collaboration runs the analysis, so the numbers are reproducible and nobody installs anything. It sees plaintext; it is yours.
  • Text is a CRDT (Yjs) in every browser and on the hub; offline edits merge on reconnect.
  • Every project is a plain git repo. A remote makes the hub disposable: each hub writes only its own CRDT file, so hubs never conflict.
  • Signatures, not the server, attest authorship: a clone verifies them offline (refs/notes/provenance).
  • Three containers: the hub (no podman), the sandbox service (podman's socket, fixed flags), egress (public HTTPS only).
